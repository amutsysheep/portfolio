# Portfolio

Welkom! Hier staan de projecten die ik tijdens mijn opleiding en in mijn vrije tijd heb gemaakt. Een deel heb ik zelfstandig gebouwd, een deel in teamverband. Klik op een projectnaam om de code te bekijken.

---

## Projecten

### 🔍 [GeoTrace](GeoTrace)
*Samen met een klasgenoot*

Een forensische ICT-website met een zelfgemaakte AI die afbeeldingen met elkaar kan vergelijken. Het doel is om onderzoekers te helpen overeenkomsten tussen beelden snel te vinden.

### 💉 [Vacinatie_app](Vacinatie_app)
*Zelfstandig project*

Een app die ik heb gemaakt voor mijn moeder, die in de zorg werkt. De app maakt het bijhouden van documentatie eenvoudiger en sneller, zodat er meer tijd overblijft voor de zorg zelf. Een project voor een echte gebruiker, met echte wensen.

### 🎭 [FOH](foh)
*Groepsproject – examentraining (lopend)*

Een website waarop opera's kunnen worden beheerd en kaartjes verkocht. Met een inlogsysteem met verschillende rollen en een beheerdersdashboard om voorstellingen toe te voegen en te wijzigen.

**Technieken:** PHP, PDO, MySQL, Composer

### 🚗 [GreenShift](greenshift)
*Groepsproject*

Een website voor een rijschool waar klanten daadwerkelijk rijlessen kunnen kopen en via een agenda kunnen inplannen.

**Technieken:** PHP, Composer, PHPMailer

### 📦 [Pas Pakket Afhaal Service](pas-pakket-afhaal-service)
*Groepsproject*

Een website waarmee gebruikers een pakket kunnen aanmelden dat opgehaald moet worden. Het systeem regelt de aanvraag en de afhandeling van de ophaalopdracht.

**Technieken:** PHP, Composer, PHPMailer

### 🖥️ [GamePC](gamepc)
*Mijn eerste groepsproject*

Een webshop voor gaming-pc's. Een eenvoudig project, maar wel het begin: hier leerde ik voor het eerst samenwerken aan een website.

---

## Projecten lokaal draaien

De PHP-projecten gebruiken Composer. Installeer de benodigde pakketten in de projectmap met:

```
composer install
```
